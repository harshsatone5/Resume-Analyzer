# Impeccable Design Skill

This skill guides the creation of high-end, premium web applications that feel fluid, delightful, and visually breathtaking.

## Core Pillars of Impeccable Design

1. **Optical Hierarchy & Balance**:
   - Primary elements command immediate focus with intentional contrast.
   - Secondary and tertiary elements recede gracefully with subtle tones (e.g. `zinc-400`, `zinc-500`) without losing readability.
   - Use consistent vertical rhythm (multiples of 4px / 8px).

2. **Micro-Interactions & Motion**:
   - Every interactive element must provide tactile feedback: hover states, active depression (`active:scale-[0.98]`), and smooth transitions (`transition-all duration-150 ease-out`).
   - Modals and popovers emerge with soft blur (`backdrop-blur-md`) and gentle fade-ins.

3. **Curated Color & Contrast**:
   - Avoid harsh pure blacks (`#000000`) or primary colors; use rich dark slates (`#121316`, `#18191e`) paired with tailored accents (e.g. indigo, emerald, sky, violet).
   - Ensure WCAG AA contrast for all textual content.

4. **Typography & Typesetting**:
   - Use premium typefaces (Google Sans, Inter, Merriweather, JetBrains Mono).
   - Strict tracking: tighten large headers (`tracking-tight`) and loosen uppercase labels (`tracking-wider text-[11px]`).
   - Line height tuned to font size (e.g., `leading-relaxed` for prose, `leading-tight` for titles).

5. **Polish Checklist**:
   - No cut-off borders or overflow artifacts.
   - Rounded corners tailored to component size (e.g., `rounded-xl` for cards, `rounded-lg` for badges).
   - Subtle borders with alpha channel (e.g., `border-white/10` or `border-zinc-800`).
