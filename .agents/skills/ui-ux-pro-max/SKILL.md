# UI/UX Pro Max Skill

This skill guarantees frictionless user flows, intuitive ergonomics, and maximum user delight across all screen sizes.

## UI/UX Engineering Rules

1. **Information Architecture & Ergonomics**:
   - Split-screen workflows must synchronize in real time without lag or layout shifting.
   - Sticky controls ensure action buttons are always accessible without continuous scrolling.
   - Collapsible accordions with quick visual counts (e.g. badge showing item count) keep complex forms digestible.

2. **Form Interactions & Feedback**:
   - Provide instant inline actions: "Enhance AI", "Duplicate", "Move Up/Down", "Delete".
   - Clear confirmation before destructive operations (`Clear All`).
   - Tag inputs must support both keyboard delimiters (<kbd>Enter</kbd>, <kbd>,</kbd>) and 1-click popular suggestion chips.

3. **Status & Progress Transparency**:
   - Include a Profile Completeness score with actionable hints ("Add a professional summary to reach 100%").
   - Clear loading indicators with animated spinners and descriptive labels during async tasks.

4. **Keyboard Accessibility**:
   - Support standard shortcut triggers (<kbd>Ctrl/Cmd + P</kbd> for PDF export, <kbd>Ctrl/Cmd + S</kbd> for quick save).
   - Clear visible focus rings (`focus:ring-2 focus:ring-indigo-500/50`).

5. **Responsive Adaptability**:
   - Mobile devices switch effortlessly between edit mode and preview mode with sticky segmented tabs.
   - Touch targets must be at least 44x44px.
