# Humanized Landing Page Design

Landing pages must feel crafted by a thoughtful human designer, not generated by an algorithm.

## Anti-AI-Slop Checklist

1. **No Generic SaaS Patterns**:
   - Avoid identical three-column feature grids with icon-title-description cards.
   - Break visual monotony: alternate between full-width, split-hero, staggered grid, and editorial layouts.
   - Never stack more than 2 visually identical card rows without a visual break.

2. **60-30-10 Color Architecture**:
   - 60% dominant surface (dark canvas: `#0c0d12`, `#0f1014`).
   - 30% secondary surfaces (cards, sections: `rgba(255,255,255,0.03)`, `#15161b`).
   - 10% accent for CTAs, badges, highlights (a single curated hue, never pure saturated).
   - Use warm neutral undertones in grays (slate not zinc) for approachability.

3. **Editorial Hierarchy — Promise → Proof → Action**:
   - **Promise**: Hero with bold claim, emotional not technical. Keep under 12 words.
   - **Proof**: Social proof, metrics, mini-demos, or visual demonstrations.
   - **Action**: Single clear CTA per viewport. Never two equal-weight buttons.

4. **Visual Anchors & Rhythm**:
   - One dominant visual element per scroll section (a mockup, illustration, or metric).
   - Vary section padding: alternate generous (120px) and tight (80px) spacing.
   - Use asymmetric layouts occasionally — not everything is centered.

5. **Authentic Microcopy**:
   - Write in first person plural ("We" or "Your") not system-speak.
   - Button text should be action-oriented outcomes ("Start Building" not "Submit").
   - Error states guide toward resolution, never dead-end with "Error occurred".

6. **Typography Texture**:
   - Mix weights within headings (bold + light in same line) for visual interest.
   - Use font size jumps of at least 1.5x between hierarchy levels.
   - Headlines: tight tracking (-0.02em). Body: natural. Labels: wider (+0.05em).
